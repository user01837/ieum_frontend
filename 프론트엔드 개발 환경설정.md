## **프론트엔드 개발 환경 설정**



###### **1. 프로젝트 의존성 설치**



프로젝트 폴더에서 아래 명령을 실행합니다.



npm install



package.json에 있는 라이브러리가 모두 설치됩니다.



==========================================================================

###### **2. 새로운 라이브러리 설치 시**



새로운 라이브러리를 설치한 경우 package.json과 package-lock.json이 자동으로 변경됩니다.



예시



npm install axios



변경된 파일을 함께 커밋합니다.



git add package.json package-lock.json

git commit -m "Add axios"

git push



다른 팀원은 아래 명령으로 최신 라이브러리를 설치합니다.



git pull

npm install



===================================================================

###### **3. 환경변수(.env) 설정**



프로젝트 루트에 .env 파일을 생성합니다.

예시는 .env.example에 적어두었으니 해당 내용 보고 각자 환경에 맞게 작성해주세요

예) VITE\_API\_BASE\_URL=http://localhost:8000



.env 파일은 Git에 올라가지 않으므로 각자 생성해야 합니다.



======================================================================

###### **4. 개발 서버 실행**

npm run dev



실행 후 아래 주소로 접속합니다.



Front : http://localhost:5173



=====================================================================

###### **5. 환경변수(.env) 수정 시**



.env를 수정한 경우에는 개발 서버를 다시 실행해야 합니다.



Ctrl + C

npm run dev



======================================================================

###### 📌 **개발 시작 순서**

git pull

npm install (package.json이 변경된 경우)

.env 확인

npm run dev
